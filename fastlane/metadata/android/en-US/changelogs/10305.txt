Fixes for the new Relay Chat (Rooms) group chat. Upgrading no longer marks every message you had already read as new — the previous update invented an unread backlog out of your existing history, and this release repairs it. Rooms now show their own unread count next to the room name (alongside the per-hub count), so you can see where the new messages are without opening each one, and the room list shows the topic and whether a room is muted. Unread badges are now a muted pill rather than red; red is reserved for when someone actually names you with @nick or @ plus part of your identity hash. And typing no longer hides the conversation: the keyboard now shrinks the message list instead of covering the newest messages, using the same fix already used in direct messages.
